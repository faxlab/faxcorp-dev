Company

FAXCORP is a small independent studio that makes software, Unreal Engine tools and games. It is run by its founder, a 3D generalist and real-time graphics developer, and every product is designed, built and supported in-house.

The work started in real-time 3D and game environments in 2012, moved to Unreal Engine content in 2018 and to games on Steam in 2019. Today it covers desktop software (SysCap), web software (zoneq), editor tools (Spline Architect, TopoTopo) and games. FAXCORP is the trading name of MB „Faxcorp“, registered in Lithuania in 2026.
