Products

Each product has its own website with downloads, documentation and support. This page is an overview.

SysCap

Disk, process and network navigator for Windows 10 and 11 · Open beta, free while in beta, Pro is a one-time purchase

SysCap draws a folder or a whole drive as a live 3D map, sized by space, and places the programs and network connections that touch it on the same map. You can see which folder is growing, which program writes to it, and where that program's connections go.

zoneq

Audio-reactive visual sequencer · Web, Windows · Preview

Build shader patches in the zoneq Studio, publish them with a link and play them anywhere: in the browser, as a desktop wallpaper or as an OBS source for live streams. Made for VJs, streamers and anyone who wants visuals that follow the music.

zoneq.app

Spline Architect

Unreal Engine plugin · Version 6 · Unreal Engine 5.5 to 5.8

Spline Architect builds along splines in the Unreal editor: walls, fences, buildings, roads and curves from your own meshes. Version 6 adds street networks, lot zones and PCG-ready city data on Unreal Engine 5.8.

TopoTopo

Procedural geometry engine · Open source, Apache-2.0

You describe geometry as a node graph in JSON; TopoTopo cooks it headless and deterministic, without an editor or a GPU, and exports it to Unreal Engine (PCG, Landscape), Blender and Houdini. It comes with a command line tool and an MCP server for AI assistants.
