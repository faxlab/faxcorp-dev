Real-time graphics software, Unreal Engine tools and games

FAXCORP is a small independent software studio in Kaunas, Lithuania. We make desktop and web software, tools and content for Unreal Engine, and small games. Everything is designed, built and supported in-house.

We have worked in real-time 3D since 2012, published Unreal Engine content since 2018 and released games on Steam since 2019.

Products

SysCap

Windows 10 and 11 · Open beta

A disk, process and network navigator. It draws a folder or a whole drive as a live 3D map and shows which programs use it and where they connect.

zoneq

Web, Windows · Preview

An audio-reactive visual sequencer. Build shader patches, share them with a link, and run them in the browser, as a desktop wallpaper or as an OBS source.

Spline Architect

Unreal Engine 5.5 to 5.8 plugin · Version 6

Build along splines in the Unreal editor: walls, buildings, curves, street networks and PCG-ready city data.

TopoTopo

Open source, Apache-2.0

A procedural geometry engine. Geometry is a node graph in JSON, cooked headless and exported to Unreal, Blender and Houdini.
